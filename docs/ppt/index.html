05 — 만들면서 느낀 점

사람이 검토하던 시간을 줄이고,
사람이 놓치던 것을 없앴습니다

시간

반복되는 데이터 추출과 수식 대입은 사람이 할 일이 아니었습니다. 세 시간이 3분 이하가 되니 같은 하루에 훨씬 많은 안을 검토합니다.

누락

사람은 바쁘면 건너뜁니다. 기계는 매번 같은 항목을 같은 방식으로 계산합니다. 품질 업무에서 이 차이는 생각보다 큽니다.

남는 일

무엇을 설계할지 정하는 것, 결과를 의심하는 것, 시험생산으로 확인하는 것. 사람이 할 일은 오히려 선명해졌습니다.

앞으로는 반복 업무에서 벗어나 더 창의적인 일에 시간을 쓰는 쪽으로 가야겠다고 느꼈습니다.
