# 강종 설계 워크벤치

스테인리스강 4개 계열의 **성분·제조조건 → 물성** 예측과, 그 역방향인 **물성 목표 → 성분 또는 제조조건** 역산을 한 화면에서 수행하는 단일 파일 웹 도구입니다.

| 계열 | 기준 강종 | 특징 |
|---|---|---|
| Austenite계 | STS 304 | 용체화 후 완전 오스테나이트, TRIP(Md30)이 연신·인장을 지배 |
| Martensite계 | STS 410 | 최종 소둔온도가 Ac1을 넘는 순간 물성이 급변 |
| Semi-Ferrite계 | STS 430 | γmax ≈ 42 %, 리징·r값이 성형성을 좌우 |
| Fully-Ferrite계 | STS 439 | Ti 완전 안정화로 γmax = 0, 예민화가 원리적으로 차단 |

## 기능

- **순방향** — 성분 13종(C, Si, Mn, P, S, Cr, Ni, Mo, Ti, Nb, Cu, N, Al)과 열연·냉연 공정 13항목을 입력하면 결정립 이력을 거쳐 YS·TS·EL·HV와 공식전위·임계전류밀도를 계산합니다.
- **역설계** — 물성 값을 직접 입력하면 성분과 제조조건 중 무엇으로 맞출지 선택할 수 있습니다. **단위 원가당 물성 변화량**(감도 ÷ 원가탄력도)이 큰 노브부터 이분법으로 목표에 접근하며, 규격을 깨뜨려 기각된 후보와 그 사유까지 기록합니다.
- **변경 요약** — 무엇을 얼마나 바꿨고, 어떤 야금 경로를 거쳤으며, 물성·원가가 얼마나 움직였고, 새로 발생한 규격 위반이 있는지를 계열마다 정리합니다.
- **원가** — 원소별 함유량 × 단가에 정련 페널티(탈황·탈탄·탈질)와 공정별 가공비를 더해 USD/톤을 산출하고, 원소별 기여도를 막대로 분해합니다. 단가는 화면에서 바로 바꿀 수 있습니다.
- **Ni 절감 최적화** — Md30 등가(±12 ℃), PREN, δ, 용접 FN, ASTM A240 기계적 규격을 모두 유지한 채 N·Cu·Mn으로 Ni를 치환하는 최소원가 조합을 탐색합니다.
- **페르소나 검증** — 레드(야금 타당성) · 블루(조업 가능성) · 그린(원료 원가) · 옐로(시장성) · 블랙(모델 정합) 5인이 현재 설계를 10점 만점으로 심사합니다. 전원 9.0 이상이어야 승인이며, `자동 개선`은 지적사항을 감점 순으로 반복 반영합니다.
- **설계 문의** — 현재 계산 상태를 읽어 답하는 문답 패널.

## 적용 회귀식

공개 문헌의 회귀식과, 이를 각 강종의 실측 대표값에 맞춰 보정한 내부 상관식을 조합했습니다.

| 구분 | 식 |
|---|---|
| Cr·Ni 당량 | Hammar & Svensson (1979) |
| δ-페라이트 | Hull 식 + 온도의존 경계 b(T) |
| 용접 페라이트수 | WRC-1992 등FN선 선형근사 |
| 가공유기 마르텐사이트 | Nohara (1977), Angel (1954) |
| Ms | Eichelman & Hull (1953), Andrews (1965) |
| 오스테나이트계 강도 | Pickering (1976) |
| 페라이트계 강도 | Hall–Petch (ky = 0.6 MPa·m^½) + 고용강화 |
| 400계 조직 | γmax 회귀, Kaltenhauser 페라이트 인자 (1971) |
| 결정립 성장 | Beck 형 `d^n − d₀^n = k₀·exp(−Q/RT)·t·Z` |
| 내공식성 | PREN = Cr + 3.3Mo + 16N 기반 Epit 상관식 |

## 빌드

```bash
./build.sh
```

`src/index.html`(셸)과 `src/0*.js`(모델·솔버·렌더러)를 합쳐 `dist/index.html` 단일 파일을 만듭니다. 의존성·빌드 도구·네트워크 요청이 전혀 없으므로 산출물을 브라우저로 바로 열면 됩니다.

```
src/
  index.html      화면 구조와 스타일 (라이트/다크 양쪽 토큰)
  01-model.js     원소·공정 항목 정의, 강종 기준값, 야금 회귀식
  02-compute.js   순방향 모델 (조직 → 물성 → 원가)
  03-solve.js     상태, 야금 제약, 조업 가능성, 역설계 솔버
  04-persona.js   페르소나 검증과 자동 개선
  05-render.js    탭·보드·열이력·베이·변경 요약 렌더링
  06-events.js    입력 이벤트, 변경 기록, 툴바
  07-ask.js       원료 단가 패널, 문답 엔진
```

## 한계

Fe–Cr–Ni 유사이원계를 온도의 함수로 매개변수화한 **준경험적 대리모델**이며, CALPHAD 엔진(Thermo-Calc 등)을 직접 호출하지 않습니다. 예측값은 AISI 304/410/430/439의 문헌 실측 범위와 대조해 보정했으나, 실제 조업 적용 전에는 반드시 실험로 검증이 필요합니다.
